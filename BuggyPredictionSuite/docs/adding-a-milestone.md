# Aggiungere una nuova milestone

1. Creare un modulo Maven, per esempio `milestone-2`.
2. Aggiungerlo alla sezione `<modules>` del `pom.xml` root.
3. Usare un package dedicato, per esempio `it.university.buggyprediction.milestone2`.
4. Conservare gli output dentro il modulo (`milestone-2/output`).
5. Non inserire il codice di una nuova milestone nel modulo `milestone-1`.

La root del progetto non prende il nome da una singola milestone e rimane il punto di aggregazione comune.
